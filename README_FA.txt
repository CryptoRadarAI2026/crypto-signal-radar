Crypto Signal Radar AI - نسخه نمایشی ۰.۱

این بسته یک پنل فارسی آزمایشی است؛ معاملات و قیمت‌ها کاملاً ساختگی هستند.
به هیچ صرافی متصل نیست و هیچ سفارش واقعی ارسال نمی‌کند.

مشاهده سریع روی گوشی:
فایل ZIP را استخراج کنید و index.html را با مرورگر باز کنید.
برخی مرورگرها اجازه اجرای فایل محلی را نمی‌دهند؛ در این صورت نیاز به میزبانی وب است.

نصب مانند اپلیکیشن اندروید (PWA):
باید این پوشه روی یک آدرس HTTPS میزبانی شود (یا localhost).
آن آدرس را در Chrome اندروید باز کنید و از منو گزینه Install app یا Add to Home screen را بزنید.
باز کردن مستقیم index.html از حافظه گوشی، نصب PWA را تضمین نمی‌کند.

هیچ رمز یا API Key در این پنل وارد نکنید.
