# پژوهش AI با تاریخچه واقعی (فقط معاملات مجازی)

این ماژول **مستقل از فایل‌های قدیمی پروژه** است. مخزن و پایگاه داده `radar.db` را تغییر نمی‌دهد. هیچ کلید API، سفارش واقعی یا اتصال حساب صرافی ندارد.

- اجرا فقط با دستور دستی در GitHub Actions آغاز می‌شود؛ هیچ پردازش ۲۴ساعته‌ای راه نمی‌اندازد.
- سه بازار BTC-USD، ETH-USD و SOL-USD را با کندل ۱ دقیقه از Coinbase Exchange عمومی درخواست می‌کند (۹۰ یا ۱۲۰ روز).
- در صورت کمبود داده، قطع اتصال، خطای منبع یا کیفیت ناکافی آموزش متوقف می‌شود. داده ساختگی جایگزین نمی‌کند.
- از ویژگی‌های گذشته و تقسیم زمانی با فاصله ایمنی استفاده می‌کند؛ مدل‌ها Logistic Regression و Random Forest هستند.
- نتیجه را بر دوره ندیده ارزیابی می‌کند و مفروضات کارمزد/لغزش فرضی را ثبت می‌کند؛ این عملکرد بازار واقعی نیست.
- گزارش JSON در Artifacts ذخیره می‌شود و مدل **هرگز مجوز معاملات واقعی یا خودکار دریافت نمی‌کند**.

برای اجرا پس از تأیید و ادغام درخواست تغییر: تب **Actions** ← **Historical Market AI Research (Paper Only)** ← **Run workflow**. اجرای اول با ۹۰ روز توصیه می‌شود؛ اتصال منبع داده از GitHub ممکن است در بعضی شرایط خطا بدهد. در صورت موفقیت، گزارش از پایین همان اجرای Actions دریافت می‌شود.

**محدودیت:** این فقط مرحله آموزش تاریخچه کندل است؛ اطلاعات دفتر سفارش، اخبار، داده بنیادی و بازار فیوچرز در این آموزش وجود ندارند. هیچ درصد موفقیت یا سود تضمین نمی‌شود. استفاده از داده عمومی تابع شرایط ارائه‌دهنده است.
